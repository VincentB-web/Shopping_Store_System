🛒 Shopping Store Management System

A web-based Shopping Store Management System designed to provide a centralized interface for managing essential store operations, including Point of Sales (POS) and inventory management.

📌 Overview

The Shopping Store Management System is a web development project focused on simplifying basic retail store operations through an organized administrative dashboard.

The system features a login interface and an administrator dashboard that serves as the entry point for different store management modules.

✨ Features

Currently Implemented / Present in the Interface

- Administrator Login – Login interface with username and password fields.
- Admin Dashboard – Centralized dashboard for accessing store management modules.
- Point of Sales (POS) – Dedicated section for accessing the POS module.
- Inventory Management – Dedicated section for accessing the inventory module.

Note: The features above describe the existing interface and navigation structure. Their complete functionality may still be under development.

🛠️ Technologies Used

- HTML5 – Web page structure and content.
- CSS3 – Styling and interface design.
- JavaScript – Client-side scripting and interactivity.

🚀 Installation and Setup

Follow these steps to run the project locally.

1. Clone the Repository

git clone https://github.com/VincentB-web/Shopping_Store_System.git

2. Navigate to the Project Directory

cd Shopping_Store_System

3. Open the Project

Open "login.html" in your preferred web browser.

Alternatively, use Visual Studio Code with the Live Server extension for local development.

💻 Usage

1. Open the login page.
2. Enter the required username and password.
3. Access the administrator dashboard when authentication is implemented.
4. Navigate through the available management sections:
   - Point of Sales
   - Inventory
